Nepal address catalogue

Dataset: https://github.com/abinrimal/nepal-administrative-divisions-json
License: MIT (LICENSE.txt). Retrieved 2026-11-03.

nepal.json contains 7 provinces, 77 districts, 753 local levels. IDs are application identifiers, not official administrative codes. Local-level IDs combine province, district and English name/type, because source local-level codes represent types and are not unique.

Correction: the source's second duplicate Chatrakot entry in Gulmi was replaced with Dhurkot (धुर्कोट), which was missing. Verified against https://daogulmi.moha.gov.np/post/dhurkot-rural-municipality and https://dccgulmi.gov.np/lg-contact .

Keep IDs stable when updating names. Existing free-text member addresses are retained and are not automatically assigned to a region.
